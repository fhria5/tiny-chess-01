Original 4KB Python chess engine for [make.fun's tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01): 10x12 board, PVS with aspiration windows, two-tier transposition table, PeSTO tapered eval, quiescence, killer + history ordering, null-move, reverse futility and late move reductions. Fixed 85,000 nodes/move.

Run: `python3 main.py` (talks to the env at MAKEFUN_ENV_URL).
