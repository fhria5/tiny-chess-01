# tiny-chess-01

Original 4KB Python chess engine for make.fun tiny-chess-01: 0x88 board, negamax alpha-beta with iterative deepening to a fixed 120,000 nodes/move, quiescence, transposition table, MVV-LVA + killer ordering, null-move pruning.

Run: `python3 main.py` (talks to the env at MAKEFUN_ENV_URL).
